Digital Clock — Day 4 Internship Task

A simple and responsive digital clock built using HTML, CSS, and JavaScript as part of my Day 4 Web Development Internship at Veda Technology.

About the Project

This project displays the current local time in HH:MM:SS format. The clock updates automatically every second without refreshing the page.

Features

- Displays the current local time.
- Updates automatically every second.
- Shows leading zeros for single-digit values.
- Simple and responsive design.
- Displays the current date.
- Works without external libraries or frameworks.

Technologies Used

- HTML5
- CSS3
- JavaScript

Project Files

- "index.html" — Website structure
- "style.css" — Design and layout
- "script.js" — Clock functionality
- "README.md" — Project documentation

How to Run

1. Download or clone this repository.
2. Open "index.html" in your browser.
3. The digital clock will start automatically.

JavaScript Concepts Learned

- "Date()" to get the current time.
- "setInterval()" to update the clock every second.
- "padStart()" to add leading zeros.
- DOM manipulation to display the time on the webpage.
